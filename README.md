# Frontier Sparks — public RSS proxy

`feed.xml` is a proxy of the canonical Frontier Sparks RSS feed. It is
identical except for the iTunes `author`/`owner` metadata that podcast
directories (Spotify, Apple) require for ownership verification, which the
canonical feed service cannot emit.

Regenerated automatically after each episode publish by
`build-feed.py`. Do not edit `feed.xml` by hand.
